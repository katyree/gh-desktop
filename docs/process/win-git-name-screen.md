# WinGit release-name screen

Screened on 2026-09-01. This is a preliminary engineering check, not legal
advice or a trademark clearance.

## Result

**Do not treat WinGit as cleared for public distribution.** Public searches did
not reveal a current Git desktop application using the exact stylization, but
the term is crowded:

- a United States **WINGIT** registration exists for unrelated footwear goods
  ([registration summary](https://trademarks.justia.com/874/89/wingit-87489420.html));
- the UK trademark journal includes recent WINGIT-form marks in multiple
  classes ([UKIPO journal PDF](https://www.ipo.gov.uk/t-tmj/tm-journals/2025-002/jnl.pdf));
- older software documentation uses “WinGit” for a Git GUI, and “WinGit” is
  easily confused in speech and search with Microsoft's **WinGet** package
  manager.

Repository, package, protocol, executable, application ID, installer, and icon
names are internally consistent and do not use GitHub Desktop identity. That is
a technical namespace check only.

## Public-release gate

Before a public release, obtain a professional search covering relevant
software and hosted-service classes, target countries, common-law use, package
registries, app stores, domains, and confusingly similar names. If counsel does
not clear WinGit, choose a new name before acquiring certificates, signing
accounts, update infrastructure, or store listings; those assets should not
cement a provisional name.
